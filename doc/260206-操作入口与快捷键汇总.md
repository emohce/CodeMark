# CodeRemarkTour 插件 - 操作入口与快捷键汇总

**基线**：2026-02-06，基于当前代码库静态梳理，供后续更新优化参考。

---

## 1. 操作入口（按位置）

### 1.1 主界面 - Tool Window

| 入口 | 说明 | 配置位置 |
|------|------|----------|
| **View → Tool Windows → CodeRemarkTour** | 打开/聚焦书签侧边栏 | `plugin.xml` → `<toolWindow id="CodeRemarkTour">` |
| 侧边栏图标 | 点击右侧边栏的插件图标打开 | 同上，`anchor="right"` |

- 实现：`CodeRemarkTourToolWindowFactory`，内容为 `BookmarkPanel`。

---

### 1.2 编辑器 - 右键菜单（EditorPopupMenu）

| 菜单项 | Action ID | 说明 |
|--------|-----------|------|
| Add CodeMark Here / Edit CodeMark | `CodeRemarkTour.CreateBookmarkAtCaret` | 当前行无 CodeMark 时显示「Add CodeMark Here」并创建；有则显示「Edit CodeMark」并打开编辑 |
| Delete CodeMark | `CodeRemarkTour.DeleteCodeMarkAtCaret` | 仅当当前行存在 CodeMark 时显示；删除该节点（带确认） |
| Next CodeMark | `CodeRemarkTour.NextCodemark` | 全局树序下一可导航节点 |
| Prev CodeMark | `CodeRemarkTour.PrevCodemark` | 全局树序上一可导航节点 |
| Add Process Entry Here | `CodeRemarkTour.CreateProcessAtCaret` | 在光标处创建 Process 入口 |
| Add Group Here | `CodeRemarkTour.CreateGroupAtCaret` | 在当前选择下创建 Group |
| Add Note Here | `CodeRemarkTour.CreateNoteAtCaret` | 在当前选择下创建 Note |

- 配置：`plugin.xml` → `<actions>`，`<add-to-group group-id="EditorPopupMenu" anchor="last"/>`。
- 实现类：`CreateBookmarkAtCaretAction`、`DeleteCodeMarkAtCaretAction`、`NextCodemarkAction`、`PrevCodemarkAction`、`CreateProcessAtCaretAction`、`CreateGroupAtCaretAction`、`CreateNoteAtCaretAction`（`presentation/action/`）。

---

### 1.3 编辑器 - Gutter（行号旁图标）

| 操作 | 说明 | 代码位置 |
|------|------|----------|
| **左键点击图标** | 在树中选中对应节点、显示 Tool Window、并高亮该行 | `BookmarkHighlighterService.kt` → `getClickAction()` "Select Bookmark" |
| **右键图标 → Edit** | 打开该节点编辑对话框 | `getPopupMenuActions()` → "Edit" |
| **右键图标 → Add Bookmark After This Node** | 在该节点后插入新 Bookmark | "Add Bookmark After This Node" |
| **右键图标 → Next CodeMark** | 全局树序下一可导航节点 | "Next CodeMark" |
| **右键图标 → Prev CodeMark** | 全局树序上一可导航节点 | "Prev CodeMark" |
| **右键图标 → Delete** | 删除该节点 | "Delete" |

- 实现：`BookmarkHighlighterService` 中 `GutterIconRenderer` 的 `getClickAction()` 与 `getPopupMenuActions()`。
- Gutter 图标由 `BookmarkLineEndPainter` 等与高亮服务配合绘制。

---

### 1.4 Tool Window 内 - 工具栏按钮

| 按钮 | 功能 | 对应方法（BookmarkPanel） |
|------|------|---------------------------|
| Refresh | 刷新树 | `BookmarkIntent.Refresh` |
| Collapse All | 全部折叠 | `collapseAll()` |
| Expand Current | 展开到当前节点并选中（无缓存时置灰） | `expandToCurrent()` |
| Query + 搜索框 | 输入即搜（300ms debounce）、匹配字符高亮、↑↓ 在匹配间移动、Enter 确认并更新缓存 | `liveSearch()`、`searchMatchRows`、树 KeyListener |

- 实现：`BookmarkPanel.kt` 工具栏区，仅保留上述 3 按钮 + 搜索框。

---

### 1.5 Tool Window 内 - 树右键菜单（PopupMenu）

| 菜单项 | 功能 |
|--------|------|
| Add Group | 创建分组 |
| Add CodeMark | 创建书签 |
| Add Note | 创建描述性笔记 |
| Edit | 编辑选中节点 |
| Move | 移动选中节点 |
| Delete | 删除选中节点 |
| Prev in Process | 流程内上一项 |
| Next in Process | 流程内下一项 |
| Refresh | 刷新 |
| Jump to current | 定位并展开到缓存中的当前节点（无缓存时置灰） |

- 实现：`BookmarkPanel.createPopupMenu()`。  
- 空白区域右键与节点右键共用同一菜单；「Jump to current」在无当前节点时禁用。

---

### 1.6 Tool Window 内 - 树交互（无菜单）

| 操作 | 功能 |
|------|------|
| 树节点单击 | 选中并导航到书签/流程入口（单次左键即导航） |
| 树 Left / Right | 折叠/展开节点或移动选中（见下方快捷键） |
| 拖拽 | 通过 `NodeTransferHandler` 支持拖放调整结构 |

## 2. 快捷键汇总

### 2.1 全局/编辑器处注册（plugin.xml，可被 Keymap 修改）

| 快捷键 | Action ID | 说明 |
|--------|-----------|------|
| **Shift+F2** | `CodeRemarkTour.CreateBookmarkAtCaret` | 在光标处添加/编辑 CodeMark |
| **Alt+Shift+Down** | `CodeRemarkTour.NextCodemark` | 全局下一 CodeMark |
| **Alt+Shift+Up** | `CodeRemarkTour.PrevCodemark` | 全局上一 CodeMark |
| **Shift+F3** | `CodeRemarkTour.CreateGroupAtCaret` | 添加 Group |
| **Shift+F4** | `CodeRemarkTour.CreateNoteAtCaret` | 添加 Note |

- `CreateProcessAtCaret`、`DeleteCodeMarkAtCaret` 未在 plugin.xml 中配置默认快捷键，可通过右键或 Keymap 自行绑定。
- 插件启动时会检查上述 Action 与系统 Keymap 冲突并提示（`checkShortcutConflicts()`），检测列表含 NextCodemark、PrevCodemark、DeleteCodeMarkAtCaret 等。

---

### 2.2 Tool Window 内 - 树获得焦点时

| 快捷键 | 功能 |
|--------|------|
| **Ctrl+F** | 焦点移到搜索框 |
| **Alt+↑** | 流程内上一项 |
| **Alt+↓** | 流程内下一项 |
| **Enter** | 导航到选中书签/入口；**搜索激活时**：确认当前高亮匹配并更新当前节点缓存、导航 |
| **↑ / ↓** | **搜索激活时**：在匹配项间移动高亮（不更新缓存）；非搜索时：树默认行移动 |
| **Left** | 折叠节点或选中父节点 |
| **Right** | 展开节点或选中首子节点 |

- 实现：`BookmarkPanel.installShortcuts()` 与树 KeyListener（搜索时 ↑↓ Enter），通过 `bindShortcut(tree, ...)` 等绑定。

---

### 2.3 Tool Window 内 - 搜索框获得焦点时

| 快捷键 | 功能 |
|--------|------|
| **Escape** | 清除搜索、恢复展开状态、将当前高亮设为缓存，并返回焦点到树 |
| **Ctrl+Enter** | 执行搜索（输入即搜已 debounce 触发，此键可选） |

- 实现：`bindShortcut(searchField, ...)`；清除搜索时 `clearSearchAndRestore()`，`updateTree` 中恢复 `savedExpandedOnSearchStart`。

## 4. 后续可优化方向（建议）

1. **统一入口文档**：工具栏、树右键、Gutter 右键的文案与分组可对齐，便于用户记忆（如“添加书签/流程/分组/笔记”命名一致）。
2. **快捷键**  
   - 为 `CreateProcessAtCaret` 在 plugin.xml 中增加可选快捷键（或说明仅用菜单）。  
   - 树内快捷键与 IDE 常用键（如 Ctrl+F/Ctrl+R）可能冲突，可考虑改为 Alt+字母或集中在说明文档中，由用户按需在 Keymap 中调整。
3. **树右键菜单**：当前部分项已注释（Set Entry、Reference、Keymap 等），若功能保留可恢复并归类。
4. **国际化**：当前工具栏/菜单/ Gutter 多为英文硬编码，若需 i18n 可改为 `message()` 等并在此文档标注需翻译的 key。
5. **冲突检测**：`checkShortcutConflicts()` 仅包含 3 个 Action ID，若新增 plugin.xml 快捷键，可一并加入检测列表。
